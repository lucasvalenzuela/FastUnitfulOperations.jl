FastUnitfulOperations

FastUnitfulOperations provides faster matrix multiplication and sorting for arrays of Unitful quantities.

Operations on such arrays use generic Julia code instead of the optimized routines available for plain numbers (e.g., BLAS for matrix multiplication). The fast methods of this package work on the numeric values to use these routines where possible, and fall back to the regular operations otherwise.

using FastUnitfulOperations, Unitful
using SortingAlgorithms

a = rand(1000, 1000)u"m"
b = rand(1000, 1000)u"s"
c = a *ᵘ b                  # same values as a * b, computed with BLAS
uproduct!(c, a, b)          # in-place version

x = rand(10^6)u"m"
usort(x; alg=RadixSort)     # sorting algorithms that require plain numbers
usortperm(x)

Installation

Note that this package usually does not have to be directly installed by the user, instead install any of the implementing packages.

This package is available through the public registry CosmoAnalysisRegistry. Add the registry once per Julia installation, together with the General registry, which provides the dependencies:

using Pkg
Pkg.Registry.add("General")
Pkg.Registry.add(url="https://github.com/lucasvalenzuela/CosmoAnalysisRegistry")

The package requires Julia 1.12 or newer and can then be installed with:

Pkg.add("FastUnitfulOperations")

Supported arrays

The fast methods operate on Arrays and on views, reinterprets, adjoints, and transposes of them, whose elements share one numeric type and unit (e.g., all Float64 in m). Other arguments, such as sparse matrices, ranges, or Quantity[1.0u"m", 2.0u"cm"], fall back to the regular operations from Base. To use the fast methods with other array types, convert them first, e.g., uproduct(Array(a), b).

Performance

The fast methods avoid the generic code that Julia uses for arrays of quantities. The timings below are from an example run, after a first call of each function to compile it, and depend on the machine.

julia> using FastUnitfulOperations, Unitful

julia> a = rand(300, 300)u"m"; b = rand(300, 300)u"s"; x = rand(10^6)u"m";

julia> a * b; a *ᵘ b; sort(x); usort(x);

julia> @elapsed a * b
0.0146

julia> @elapsed a *ᵘ b
0.00069

julia> @elapsed sort(x)
0.0352

julia> @elapsed usort(x)
0.0179

FastUnitfulOperations.FastUnitfulOperations — Module
FastUnitfulOperations

Fast matrix multiplication and sorting for arrays of Unitful quantities.

Arrays of quantities are handled by generic Julia code, while arrays of plain numbers can use optimized routines such as BLAS. The fast methods of this package reinterpret a quantity array as an array of its numeric values without copying it, apply the routine for plain numbers, and attach the units to the result. Arguments that the fast methods do not support fall back to the regular operations from Base.

FastUnitfulOperations.uproduct! — Method
uproduct!(c, a, b)

Fast in-place matrix multiplication for Unitful arrays, storing a * b in c and returning c.

This method multiplies the numeric values with the routines for plain numbers (e.g., BLAS) and stores them in c. It throws an error if the unit of c differs from the product of the units of a and b (a unitless c requires a * b to be unitless). The method falls back to mul!(c, a, b), if an argument is not a supported array.

Examples

julia> using Unitful

julia> a = [1.0 2.0; 3.0 4.0]u"m"; b = [1.0, 2.0]u"s"; c = zeros(2)u"m*s";

julia> uproduct!(c, a, b)
2-element Vector{Quantity{Float64, 𝐋 𝐓, Unitful.FreeUnits{(m, s), 𝐋 𝐓, nothing}}}:
  5.0 m s
 11.0 m s

FastUnitfulOperations.uproduct — Method
uproduct(a, b)
a *ᵘ b

Fast matrix multiplication for Unitful arrays.

This method multiplies the numeric values with the routines for plain numbers (e.g., BLAS) and attaches the units to the result. The result has the same type as a * b. The method falls back to a * b if an argument is not a supported array.

Type *\^u followed by the tab key to input the operator *ᵘ.

Examples

julia> using Unitful

julia> a = [1.0 2.0; 3.0 4.0]u"m"; b = [1.0, 2.0]u"s";

julia> a *ᵘ b
2-element Vector{Quantity{Float64, 𝐋 𝐓, Unitful.FreeUnits{(m, s), 𝐋 𝐓, nothing}}}:
  5.0 m s
 11.0 m s

FastUnitfulOperations.usort — Method
usort(a; kwargs...)

Return a sorted copy of the unitful array a, like sort.

The elements are sorted by their numeric values, which is faster than sorting the quantities and allows sorting algorithms that only accept integers or floats (e.g., RadixSort from SortingAlgorithms). The result has the same type as sort(a). The method falls back to sort(a; kwargs...) if a is not a supported array or if any of the keyword arguments by, lt, or order is given, since these act on quantities.

Examples

julia> using Unitful

julia> usort([3.0, 1.0, 2.0]u"m")
3-element Vector{Quantity{Float64, 𝐋, Unitful.FreeUnits{(m,), 𝐋, nothing}}}:
 1.0 m
 2.0 m
 3.0 m

Developer documentation

Functions for packages that extend the fast methods to further array types.

FastUnitfulOperations.convertoperands — Function
FastUnitfulOperations.convertoperands(a, b)

Return the operands that uproduct and uproduct! pass to their fast methods in place of a and b. By default, a and b are returned unchanged.

Add methods to enable the fast methods for array types they do not support, by converting such operands to an Array (or another array type for which FastUnitfulOperations.isfastarray returns true). Only convert operands for which the product of the converted operands has the same type as a * b. If the fast methods cannot be used even with the converted operands, uproduct and uproduct! call * and mul! with the original operands.

With StaticArraysCore loaded (e.g., through StaticArrays or Rotations), a static matrix multiplied with a matrix of a supported array type is converted to a Matrix.

Examples

A method for a hypothetical matrix type MyMatrix, for which MyMatrix * Matrix returns a Matrix:

FastUnitfulOperations.convertoperands(a::MyMatrix, b::Matrix) = (Matrix(a), b)

FastUnitfulOperations.isfastarray — Function
FastUnitfulOperations.isfastarray(x)

Return whether the fast methods of this package can operate on x directly.

This is the case if x is an Array, or a view, reinterpret, adjoint, or transpose of one (also nested), and its element type is a concrete numeric type with a fixed size in memory (isbitstype). For unitful arrays, this means that all elements share one numeric type and unit.

Methods of FastUnitfulOperations.convertoperands can use this to check whether an operand they do not convert is supported by the fast methods. To support further array types, add methods to convertoperands instead of isfastarray.

Examples

julia> using Unitful

julia> FastUnitfulOperations.isfastarray([1.0, 2.0]u"m")
true

julia> FastUnitfulOperations.isfastarray(view([1.0 2.0; 3.0 4.0]u"m", :, 1)')
true

julia> FastUnitfulOperations.isfastarray(Quantity[1.0u"m", 2.0u"cm"])
false

julia> FastUnitfulOperations.isfastarray((1:3)u"m")
false
